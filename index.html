Inside the machine

Meet the Rangers robot.

Every mechanism has a job. Our robot combines a drivetrain, scoring system, and sensors that support repeatable performance.

Drivetrain · Swyft Drives

Our drivetrain uses Swyft Drives, selected for a compact setup, speed, and durability.

Scoring hood

A shaped hood guides game pieces toward a more consistent scoring trajectory. We refine its angle and geometry through testing.

Limelight vision

The Limelight camera helps identify AprilTags for alignment and can support game-piece color detection.

Odometry & pathing

Odometry pods provide movement measurements that support autonomous navigation and pathing routines.

FTC controller project format

The whole TeamCode layout.

FTC Java OpModes live inside the TeamCode module of the official FTC Robot Controller Android Studio project. You do not replace the Robot Controller app with a standalone Java file.

FtcRobotController/
├── FtcRobotController/
│   └── src/main/                 Robot Controller app source
├── TeamCode/
│   ├── build.gradle              TeamCode module configuration
│   └── src/main/
│       ├── AndroidManifest.xml
│       ├── java/
│       │   └── org/firstinspires/ftc/teamcode/
│       │       ├── MecanumAdjustableDrive.java
│       │       ├── DecodeTeleOp.java
│       │       ├── IntoTheDeepTeleOp.java
│       │       ├── BioBuzzTeleOp.java
│       │       └── RobotHardware.java
│       └── res/
├── build.gradle
├── gradle/
└── settings.gradle

Use the official SDK project and keep its Gradle files, manifests, and module configuration intact. The examples below are complete TeamCode Java files; adapt hardware names, motor directions, servo endpoints, and game-specific mechanisms to your actual robot.
