# Rangers Media Uploads

Place approved website media in these folders:

- `photos/` — JPG, PNG, or WebP team and robot photos
- `videos/` — only short, optimized video files; for longer videos, use the team's YouTube channel

GitHub Pages is a static host. It cannot receive a visitor's file upload and publish it to every visitor without a backend. To publish media, add files here, add entries to the `publishedMedia` array in `index.html` with their relative paths and captions, then commit and push the repository.

Use descriptive filenames, compress large images, and only publish media the team has permission to share. Check with teammates before posting identifiable photos or personal information.
