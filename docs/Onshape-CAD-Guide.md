# Onshape CAD guide for FTC

## Recommended learning order

1. Create a team document and name it clearly.
2. Learn the sketch plane, line, rectangle, circle, dimension, and constraint tools.
3. Fully constrain sketches so dimensions and design intent are predictable.
4. Use Extrude, Remove, Fillet, Chamfer, Hole, and Pattern to build editable parts.
5. Organize multi-part designs into Part Studios and Assemblies.
6. Use mates to position parts and check clearances and motion.
7. Create drawings with dimensions and notes before manufacturing.
8. Review the CAD against real motors, wheels, fasteners, electronics, and legal robot size constraints.

## FTC design review checklist

- Are critical dimensions driven by named parameters or sketch dimensions?
- Are mounting holes based on the actual hardware drawing or measurement?
- Is there enough room for tools, wiring, connectors, and service access?
- Do moving parts have clearance through their complete range of motion?
- Can the assembly be built and maintained with the team's available tools?
- Has the design been checked against current FTC rules and robot size limits?
