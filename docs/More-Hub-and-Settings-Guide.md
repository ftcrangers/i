# More Hub and 50 Settings

The Rangers website includes a searchable **260-tool directory** with 260 dedicated tool workspaces.

## More directory

Open **More** from the main navigation. Search by keyword or filter by category. Each directory card opens its own workspace, where visitors can save local entries and export records as CSV or JSON.

The directory includes tools across:
- **Competition:** match planning, scouting, alliance coordination, event readiness, strategy, scoring scenarios, and award planning
- **Calculators:** unit conversions, drivetrain estimates, time and cycle calculations, electrical estimates, geometry, and robot weight planning
- **Build:** bills of materials, fasteners, assembly plans, prototype comparisons, material cut lists, and design records
- **Robot care:** inspection, maintenance, battery records, wear tracking, repair notes, and transport checklists
- **Practice:** driver and operator drills, timing, consistency, autonomous rehearsal, and skills progress
- **Robot tuning:** drivetrain response, odometry, sensors, intake, lift, servo, and mechanism testing
- **CAD:** Onshape planning, constraints, fits, clearances, assemblies, drawings, print preparation, and design reviews
- **Electrical:** hub ports, motor and servo assignments, wiring, connectors, power distribution, and inspection
- **Programming:** Java and OpMode planning, hardware maps, gamepad layouts, state machines, autonomous steps, vision, PID, code review, and releases
- **Team:** task tracking, meetings, onboarding, outreach, notebook evidence, awards, sponsors, budgets, and media planning

The original 30 calculator and logging workspaces remain available. The expanded directory adds 230 more focused workspaces. These added workspaces save structured notes, measurements, owners, statuses, and results, rather than claiming to automate or validate physical robot behavior.

Records are stored in the current browser only; they do not sync between devices. Visitors can remove individual records and export records as CSV or JSON.

## 50 settings

Settings are grouped into Appearance, Navigation, Behavior, Code & learning, Team content, and Accessibility. They include theme, text scale, accent color, font, line spacing, content width, card styling, navigation behavior, default landing page, tool autosave, export format, code display options, learning panels, season details, accessibility options, and dashboard density.

The floating quick menu is **off by default**. Preferences are stored in localStorage on the visitor's device. The reset button restores the defaults and asks for confirmation when that preference is enabled.

## Notes

Calculator outputs are planning estimates, not verified robot performance. Check formulas, dimensions, game rules, electrical plans, and code with the team's mentor before relying on them in a robot or competition.
