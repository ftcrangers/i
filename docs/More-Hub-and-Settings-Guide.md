# More Hub and 50 Settings

The Rangers website now includes a searchable More directory with 100 feature entries and 30 dedicated tool workspaces.

## More directory

Open **More** from the main navigation. Search by keyword or filter by category. The 30 workspaces cover:
- Competition planning, event checklists, match timing, scoring, alliance notes, and strategy
- Gear ratios, wheel travel, encoder ticks, motor speed, servo positions, and unit conversion
- Parts costs, pit checklists, battery records, and maintenance notes
- Driver practice, cycle tracking, intake/shooter/lift tuning
- CAD measurements, material estimates, fasteners, wire planning, electrical maps
- Sensor testing, OpMode starter generation, bug tracking, code release checks, and meeting agendas

Each workspace can calculate a result or save a local record. Records can be removed and exported as CSV or JSON. Tool records and drafts are stored in the current browser only; they do not sync between devices.

## 50 settings

Settings are grouped into Appearance, Navigation, Behavior, Code & learning, Team content, and Accessibility. They include theme, text scale, accent color, font, line spacing, content width, card styling, navigation behavior, default landing page, tool autosave, export format, code display options, learning panels, season details, accessibility options, and dashboard density.

The floating quick menu is **off by default**. Preferences are stored in localStorage on the visitor's device. The reset button restores the defaults and asks for confirmation when that preference is enabled.

## Notes

The calculator outputs are planning estimates, not verified robot performance. Check formulas, dimensions, game rules, electrical plans, and code with the team's mentor before relying on them in a robot or competition.
