# Rangers Parts Hub

The Parts Hub links to SWYFT Robotics' official FTC catalog and selected product pages.

## Build list

The on-site build list is stored in the current browser only. It supports quantities, a simple "Have it" checkbox, removal, custom part names, and CSV export. It is a planning checklist, not a shopping cart and does not place orders.

## Before ordering

Product options, prices, inventory, and compatibility can change. Use the official SWYFT product page for current details. Check the current FTC game manual and your robot design before selecting components. Ask the team's coach or purchasing lead to approve orders.
