# Rangers Engineering Tools

The Rangers Hub adds four practical team tools:

- **Engineering Notebook** — record meetings, design decisions, prototype tests, programming work, and next steps. Export entries as JSON.
- **Autonomous Path Planner** — create an ordered route on a conceptual 8×8 grid and export the waypoint list as JSON. The grid is not calibrated to an official field and does not generate ready-to-run robot code.
- **Competition Scouting** — record match-by-match observations, team numbers, point breakdowns, reliability notes, and export a CSV.
- **Robot Maintenance** — keep dated subsystem inspection and service records, export a CSV, and use the pre-match visual reminder checklist.

## Data and privacy

These tools store their entries in the browser's local storage on the device being used. They do not create accounts, send records to a server, or synchronize between teammates. Clearing browser site data can erase locally stored records. Use the export buttons to keep a backup and share files only through the team's approved process.

## Team use

Use the notebook to document what was actually tested and observed. Keep scouting records clearly identified as team-entered observations rather than official event results. The autonomous planner is for route discussion; validate coordinates, field orientation, localization, and motion constraints before translating a route into robot code. Use mentor-approved inspection and repair procedures for robot maintenance.
